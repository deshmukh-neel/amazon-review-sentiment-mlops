# Model card

## Intended use

ReviewSignal demonstrates a reproducible binary sentiment-classification lifecycle. It is suitable for portfolio demonstrations and low-stakes experimentation, not automated high-stakes decisions.

## Model

The production estimator is one scikit-learn pipeline:

1. Word TF-IDF with unigrams and bigrams, `max_features=50_000`, `min_df=2`, and `sublinear_tf=True`.
2. Logistic regression with `C=1.0`, `max_iter=1000`, and `random_state=42`.

## Promotion policy

- Initial validation macro-F1 must be at least `0.85`.
- Validation macro-F1 must exceed a stratified dummy baseline by at least `0.15`.
- A replacement may not regress more than `0.01` from production validation macro-F1.
- The artifact checksum and declared library versions must match before loading.

## Reported metrics

Every candidate report contains accuracy, macro F1, positive-class precision and recall, ROC-AUC, confusion matrix, dummy macro-F1, artifact size, and single-record inference latency. Exact production results are generated by the pipeline and will replace historical notebook results in the repository landing page.

## Limitations

The score returned by the API is a model probability, not a guarantee or human-calibrated confidence. The model is binary, English-only, and can fail on sarcasm, mixed sentiment, domain-specific language, or adversarial text. Submitted text is not retained for feedback or drift analysis.
